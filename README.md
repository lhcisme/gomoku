# 五子棋 · Gomoku

15×15 标准五子棋，人机对战，三档难度。纯前端单页，零依赖、零框架，打开即玩。

**在线试玩：** https://lhcisme.github.io/gomoku/

## 功能

- 人机对战，可选 **简单 / 中等 / 困难** 三档难度
- 可选择执黑（先手）或执白（后手），AI 会自动先走
- 悔棋（自动回退到你的回合）、一键重开
- 最后一手标记、五连自动高亮
- 手机 / 平板 / 桌面自适应，点交叉点落子

## 难度设计

| 难度 | 行为 |
| --- | --- |
| 简单 | 一层贪心 + 随机扰动，会漏招，适合入门 |
| 中等 | 深度 2 搜索 + 威胁判断，偶尔犯错 |
| 困难 | 迭代加深 α-β（最深 10 层）+ 置换表 + **VCF 连杀搜索** + 完整威胁规则 |

AI 的判定顺序（越靠前越优先）：

1. 我有一步成五 → 直接下
2. 对手下一步能成五 → 必须堵
3. 我能做出**活四**或**双冲四** → 对方挡不住，直接下
4. 我能做出**双威胁**（双活三 / 活三+冲四）→ 同样必胜
5. **VCF 连杀搜索**：只看强制手（冲四/活四），一路算到底，能杀就杀
6. 对手下一步能做出活四或双威胁 → 找最优的拆招点
7. 否则走迭代加深 α-β：2→4→6→8→10 层逐层加深，超时退回上一层结果

几个关键细节：

- **置换表 + Zobrist 哈希**：同一局面不重复搜索，同样时间能多搜 2~3 层
- **VCF**：连续冲四的杀棋浅层搜索基本看不见，这是困难档「会做杀」的核心
- 评估函数专门检测「一步成五」，避免搜索在叶子节点处看不见对手的杀招
- 评分分档：连五 > 活四 > 冲四/活三 > 眠三 > 活二

## 文件

```
index.html    页面结构
style.css     界面样式
core.js       棋局规则 + AI（纯计算，不依赖 DOM，可在 Node 下测试）
ui.js         棋盘绘制与交互
test/         自测脚本
```

## 本地运行

直接双击 `index.html`，或起一个静态服务器：

```bash
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 自测

```bash
node test/core.test.js      # 规则 / 棋型 / AI 关键着法 / 自战 / 性能
node test/ui.selftest.js    # 用假 DOM 跑完整交互流程
```

## 部署

推送到 `main` 即由 GitHub Actions 自动发布到 GitHub Pages（见 `.github/workflows/pages.yml`）。
